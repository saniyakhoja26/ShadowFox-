The beginner level focused on building a strong foundation in Python programming.

### Topics Covered:

- Variables and data types
- Arithmetic operations and number formatting
- Conditional statements
- Loops
- Lists and dictionaries
- File handling
- Object-Oriented Programming (Classes & Objects)
- Inheritance

These tasks helped strengthen logical thinking and understanding of core Python concepts.

## 🟡 Intermediate Level

The intermediate level focused on applying Python concepts to real-world scenarios.

### Projects:

- **Web Scraper**  
  Extracted data from the ShadowFox website using `requests` and `BeautifulSoup`,
  implemented basic error handling, and stored scraped data.

- **Hangman Game**  
  Developed a text-based Hangman game with random word selection, user interaction,
  visual progress display, win/loss conditions, and replay functionality.
